## Overview

This project combines robotics, embedded systems, and computer vision to create lifelike animatronic eyes. I've always been fascinated by animatronics in theme parks and movies, and this was my opportunity to build something similar from scratch.

The eyes use an ESP32-CAM module to detect faces in real-time and smoothly track movement using two servo motors. Everything runs on the microcontroller itself—no external computer required. I also built a web interface to monitor the camera feed and debug the system.

## Technical Architecture

The system consists of three main components:

1. **Vision Pipeline**: ESP32-CAM module runs face detection using a lightweight computer vision algorithm
2. **Servo Control**: Custom PCB routes signals to two servos controlling horizontal and vertical eye movement
3. **Web Interface**: Real-time video feed and debug controls accessible via WiFi

The biggest challenge was optimizing the face detection to run at a reasonable framerate on the ESP32's limited 240MHz processor. I experimented with different algorithms and eventually settled on a simplified Haar cascade detector that could achieve ~10fps.

## Mechanical Design

I designed the eye mechanism in TinkerCAD, 3D printing the eyeball housing and servo mounts. The design allows for smooth, realistic movement with minimal backlash. Each eye has two degrees of freedom controlled by hobby servos.

## Results

The final prototype successfully tracks faces within a 120-degree field of view with acceptable latency. The web interface makes it easy to calibrate servo positions and monitor system performance.

## Future Improvements

There are several enhancements I'd like to make:

- Adding eyelid servos for blinking animations
- Implementing gaze prediction to anticipate movement
- Battery-powered operation for portability
- Multiple eye pairs synchronized together
