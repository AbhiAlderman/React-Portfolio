## Overview

I wanted to make an online portfolio to showcase all the different interesting projects I have worked on. This also serves as my way to get better at Front End development. This is where you are now! I am using React for this portfolio now to re-familiarize myself with React and TypeScript. Most recently, I built a portfolio using Astro, but I felt too restricted, so I switched back to React.

### Want Visuals? Just look around!

You're here now! Take a look at my other projects. This portfolio is basically just a way to display my [projects](http://localhost:5173/#projects) visuals and more detailed writeups. The navbar contains links to my resume, [LinkedIn](https://www.linkedin.com/in/abhialderman/), and Github(https://github.com/AbhiAlderman). There is also a super secret [palette page](http://localhost:5173/palette) I use for testing different color palettes!

The image above is the original home page I had when I first created an online portfolio. I've since redone the entire project twice. The second time, I tried using Astro instead of React. This definitely made development easier, but honestly I just wasn't happy with how it looked. I felt somewhat restricted by Astro. It was probably my own misunderstandings and mistakes, but it felt like I could not create the website I was envisioning with the tools I had there. There were some difficulties using markdown files for the project writeups as well, which is what I would prefer.

I'm now back to using React for this. React is definitely overkill, I could probably get something looking about the same with just basic HTML and CSS, but I wanted to practice React, TailwindCSS, and TypeScript. So an easy project like a personal portfolio is a great way to brush up on these skills. As a bonus, I now have a place to easily look back on stuff I've worked on!
