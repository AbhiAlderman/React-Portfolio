## Overview

This game was a submission to the Kenny Gam Jam 2025. We were required to use assets made by Kenny, a game asset developer and somewhat famous niche internet personality? Inspired by Jump King, in this game you leap to the top of the level while avoiding a long tumble to the bottom. Try the game on [itch.io](https://toastyfraud.itch.io/power-leap).
